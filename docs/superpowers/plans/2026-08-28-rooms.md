# Rooms Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split Squirrel's single conversation into seven rooms, each keeping its own thread, reached from a rail that never leaves the screen.

**Architecture:** `turns` gains a `room` column and every read is scoped to one room. The lid's `<details>` menu becomes a persistent rail — furniture in a left column on a desktop, its own screen on a phone. Doors stop being POSTs that append "the pile" to the record and become GETs at `/r/{room}`; a room draws its own current state the way `threadHandler` already appends the offer, guarded by `endsOpen`. The dock stays one form and one route, and carries the room as a field so the room decides the filing.

**Tech Stack:** Go 1.26, pgx/pgxpool, Postgres 17, `html/template`, embedded SQL migrations, hand-rolled CDP browser tests.

**Spec:** `docs/superpowers/specs/2026-08-28-rooms-design.md`

## Global Constraints

- **The visual system does not change.** Every token in `pile.css` — `--purple-deep #58388a` and its radial, `--card #fdecd4`, `--outline #1c110b`, `--line 3px`, `--r 14px`, the `0 5px 0 0 var(--outline)` sticker offset, Recursive's `--casual`/`--precise` axes, the Inter 900 wordmark — keeps its current value. New rules compose from these; no new colour, radius, or shadow value is introduced.
- **Room names are the product's own names**, never hash-names: `the pile`, `the agenda`, `the tasks`, `the chores`, `what you set aside`, `the things you kept`, `Buddy`.
- **Counts stay on the rail**, per the owner's decision of 27 August. Zero is no number and not a nought — a room with nothing waiting has no pill. Nothing counts what was not done, and no number survives being dealt with.
- **Inside a room nothing changes about capping.** `listLimit = 5`, `pileLimit = 1`, `threadLimit = 40` all keep their values and their meaning.
- **Every test must be mutation-proved.** Revert the code the test claims to cover and report the exact assertion-failure line observed. A compile error is not proof.
- **`go test ./...` does not compile tagged files.** Before every commit run all three: `make test`, `make test-integration` (needs `TEST_DATABASE_URL=postgres://squirrel:squirrel@127.0.0.1:55432/squirrel_test`), and `go vet -tags=browser ./internal/web/`.
- **Never commit to `main`.** This work is on `feat/rooms`. Conventional-commit subjects, lowercase, imperative.
- **Out of scope, by the spec:** per-room Buddy tool scoping (measure first), multi-person, presence, read state, cross-room search, threading, per-room notifications.

```sql
-- Which room it was said in.
--
-- The screen became one conversation on 24 August 2026 and seven on
-- 28 August; see docs/superpowers/specs/2026-08-28-rooms-design.md. A room is
-- both a place that keeps its own conversation and a scope that narrows what
-- Buddy can reach, and this column is the first half.
--
-- Text rather than an enum, for the same reason `who` is text: a new room
-- should be a phase, not a migration.
alter table turns add column if not exists room text not null default 'buddy';

-- Everything said before rooms existed was one conversation, and the room a
-- conversation lives in is Buddy's. Not the pile's: the record holds his
-- openings, his offers and his answers as well as your notes, and filing all
-- of that into the pile would say the pile is where talking happens.
--
-- The default above already writes 'buddy' into every existing row, so this
-- is the statement's documentation rather than a second pass.

-- The two queries are now per-room. Room leads: it is the equality, and
-- said_at is the range.
drop index if exists turns_person_said;
create index if not exists turns_person_room_said
    on turns (person_id, room, said_at desc, id desc);
```

```go
// AppendTurn writes one turn into one room and returns it with its id and time
// filled in.
func (s *Store) AppendTurn(ctx context.Context, personID int64, room string, t Turn) (Turn, error) {
	const q = `
		insert into turns (person_id, room, who, words, shown)
		values ($1, $2, $3, $4, $5)
		returning id, said_at`

	var shown any
	if len(t.Shown) > 0 {
		shown = t.Shown
	}
	if err := s.pool.QueryRow(ctx, q, personID, room, string(t.Who), t.Words, shown).
		Scan(&t.ID, &t.SaidAt); err != nil {
		return Turn{}, fmt.Errorf("saying it: %w", err)
	}
	t.Room = room
	return t, nil
}

// RecentTurns is the end of one room's conversation, oldest first.
func (s *Store) RecentTurns(ctx context.Context, personID int64, room string, limit int) ([]Turn, bool, error) {
	const q = `
		select id, room, who, words, shown, said_at
		  from turns
		 where person_id = $1
		   and room = $2
		 order by said_at desc, id desc
		 limit $3`
	return s.scanTurns(ctx, limit, q, personID, room, limit+1)
}

// TurnsBefore is the page above a turn you can already see, in that turn's own
// room.
func (s *Store) TurnsBefore(ctx context.Context, personID int64, room string, beforeID int64, limit int) ([]Turn, bool, error) {
	const q = `
		select id, room, who, words, shown, said_at
		  from turns
		 where person_id = $1
		   and room = $2
		   and (said_at, id) < (select said_at, id from turns where id = $3)
		 order by said_at desc, id desc
		 limit $4`
	return s.scanTurns(ctx, limit, q, personID, room, beforeID, limit+1)
}
```

```go
package web

import (
	"context"
	"net/http"
)

// The rooms, in the order the rail draws them.
//
// Buddy first because he is where you talk and where a press with nothing in
// mind should land. The four that hold things next, in the order the menu
// carried them. The two shelves last, because they are where a decision has
// already been made.
//
// A slice rather than a map: the rail has an order and a map has none, and the
// order was the one thing the menu's map could not say.
type room struct {
	// Key is the room in a URL and in the turns table.
	Key string
	// Name is what it is called. Never a hash-name — see the spec.
	Name string
	// Placeholder and Button are the dock, in this room. The button names the
	// consequence rather than the act, because the room decides the filing
	// with no confirmation step and a grey placeholder cannot carry that.
	Placeholder string
	Button      string
	// Action and Field are where the dock posts and under what name. Three
	// rooms are two-step and stay two-step: a chore needs a rhythm and an
	// appointment needs a day, and both pickers already exist — what the dock
	// replaces is the first step, a box asking for the words you have already
	// typed.
	Action string
	Field  string
}

var rooms = []room{
	{Key: "buddy", Name: "Buddy",
		Placeholder: "what's going on?", Button: "Tell it",
		Action: "/capture", Field: "text"},
	{Key: "pile", Name: "the pile",
		Placeholder: "what is it", Button: "Put it in the pile",
		Action: "/capture", Field: "text"},
	{Key: "chores", Name: "the chores",
		Placeholder: "what comes back?", Button: "Make a chore",
		Action: "/chores/name", Field: "name"},
	{Key: "at", Name: "the agenda",
		Placeholder: "what is happening?", Button: "Put it in the agenda",
		Action: "/at/new", Field: "label"},
	{Key: "tasks", Name: "the tasks",
		Placeholder: "what did you decide?", Button: "Make a task",
		Action: "/tasks/new", Field: "text"},
	// The two shelves. Nothing is kept or set aside by being typed — both are
	// reached by deciding about a note that already exists. A shelf with no
	// dock would be the one screen where the thumb has nowhere to go, so the
	// room still decides and a shelf's decision is the pile.
	{Key: "held", Name: "what you set aside",
		Placeholder: "what is it", Button: "Put it in the pile",
		Action: "/capture", Field: "text"},
	{Key: "kept", Name: "the things you kept",
		Placeholder: "what is it", Button: "Put it in the pile",
		Action: "/capture", Field: "text"},
}

func roomByKey(key string) (room, bool) {
	for _, r := range rooms {
		if r.Key == key {
			return r, true
		}
	}
	return room{}, false
}

// roomKey is the context key. Its own type, so nothing else in any package can
// collide with it.
type roomKey struct{}

// roomOf is which room this request is in. Buddy's when nobody said — a
// handler mounted outside a room still has to put its turn somewhere, and the
// somewhere is the room the whole conversation lived in before 28 August.
func roomOf(ctx context.Context) string {
	if r, ok := ctx.Value(roomKey{}).(string); ok && r != "" {
		return r
	}
	return "buddy"
}

// withRoom is how the room gets onto the request. One place sets it and
// keepSaid is the one place that reads it; see the fence in roomturns_test.go.
func withRoom(key string, h http.HandlerFunc) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		h(w, r.WithContext(context.WithValue(r.Context(), roomKey{}, key)))
	}
}
```

```go
// keepSaid writes what was said into the room the request is in.
//
// The room comes from the context rather than a parameter because thirty
// handlers call this and a thirty-first would be added without one. A turn in
// the wrong room is invisible — it looks exactly like a room that is quiet —
// so there is one place that decides, and roomturns_test.go fences it.
func keepSaid(ctx context.Context, s Store, personID int64, said []squirrel.Turn) []squirrel.Turn {
	out := make([]squirrel.Turn, 0, len(said))
	for _, t := range said {
		saved, err := s.AppendTurn(ctx, personID, roomOf(ctx), t)
		if err != nil {
			slog.Error("keeping what was said", "error", err)
			continue
		}
		out = append(out, saved)
	}
	return out
}
```

Today `/open` is a POST that appends two turns — "the pile" in your mouth, then Buddy's reply — every time a door is pressed. In a rooms world entering a room is navigation, and navigation must not write. So a room is a GET, it renders that room's stored turns, and it appends the room's own current turn only when the conversation ends with nothing to act on. That is exactly the `endsOpen` guard `threadHandler` already uses for the offer, reused rather than reinvented.

`/open` stays mounted as a redirect: an installed home screen holds a cached page whose forms still post there.

```go
// navigation must not write — the door appended "the pile" to the record on

// said.

// conversation ends with nothing to act on. Same guard the offer uses on the
// thread, for the same reason: something already handed to you is something
// you already have.
func roomHandler(s Store, opts Options) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		personID, ok := personOf(r)
		if !ok {
			fail(w, errNoOwner)
			return
		}
		here, ok := roomByKey(r.PathValue("room"))
		if !ok {
			// A typo, not a page. Not a redirect to Buddy: a URL that
			// silently becomes a different room is a URL you cannot trust in
			// a bookmark.
			http.NotFound(w, r)
			return
		}
		ctx := r.Context()

		var (
			turns []squirrel.Turn
			more  bool
			err   error
		)
		before, perr := strconv.ParseInt(r.URL.Query().Get("before"), 10, 64)
		walkingBack := perr == nil && before > 0
		if walkingBack {
			turns, more, err = s.TurnsBefore(ctx, personID, here.Key, before, threadLimit)
		} else {
			turns, more, err = s.RecentTurns(ctx, personID, here.Key, threadLimit)
		}
		unreadable := err != nil
		if unreadable {
			slog.Error("reading a room", "room", here.Key, "error", err)
			turns, more = nil, false
		}

		// The room's own current state. Never while walking back — reading the
		// past must not add to it — and never onto a conversation that already
		// ends with something to act on.
		if !walkingBack && !unreadable && !endsOpen(turns) {
```

```go
// railView is one room on the rail.
type railView struct {
	Key, Name string
	// Count is what is waiting, and zero draws no pill. Zero is no number and
	// not a nought: a room reading "0" is a scoreboard, which is the rule the
	// four doors carried and the rail inherits along with them.
	//
	// Kept against the evidence, deliberately, on 27 August 2026 — a bad week
	// reads as a scoreboard because pills in a column invite a total. The
	// reversal is one call: delete the Waiting read below and every number
	// goes, because they are computed here and stored nowhere.
	Count int
	// Current is the room you are in.
	Current bool
}

func roomsFor(ctx context.Context, s Store, personID int64, here string) []railView {
	out := make([]railView, 0, len(rooms))
	for _, r := range rooms {
		out = append(out, railView{Key: r.Key, Name: r.Name, Current: r.Key == here})
	}
	waiting, err := s.Waiting(ctx, personID, now())
	if err != nil {
		// A count that cannot be read is a rail with no numbers on it, which
		// is what this was before 24 August. Everything still goes where it
		// goes.
		slog.Error("counting what is waiting, for the rail", "error", err)
		return out
	}
	for i := range out {
		switch out[i].Key {
		case "pile":
			out[i].Count = waiting.Pile
		case "at":
			out[i].Count = waiting.Agenda
		case "tasks":
			out[i].Count = waiting.Tasks
		case "chores":
			out[i].Count = waiting.Chores
		}
	}
	return out
}
```
